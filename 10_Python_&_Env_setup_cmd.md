**- What is pyenv ?**
  pyenv is a specialized tool used specifically to install, manage, and switch between multiple, isolated versions of Python.<\br>
  Homebrew is a general-purpose package manager for macOS and Linux used to install software (e.g., git, node, python).

  When to use what:
  Homebrew: Install non-python tools like git, htop, or nginx.
  Pyenv: Install and switch between Python 3.x and 2.x, or specific patch versions.
